# Banque NOVA — Projet BTS SIO SISR

## Présentation

Banque NOVA est une banque fictive de 25 collaborateurs.

Ce projet est réalisé dans le cadre du BTS SIO option SISR.

L'objectif est de concevoir et mettre en œuvre un système d'information sécurisé, centralisé et disponible permettant aux collaborateurs d'accéder aux ressources informatiques de l'entreprise.

## Problématique

> Comment Banque NOVA peut-elle mettre en place un système d'information sécurisé, centralisé et disponible permettant à ses 25 collaborateurs d'accéder efficacement aux ressources de l'entreprise tout en protégeant les données sensibles de ses clients ?

## Objectifs

- Concevoir une architecture réseau structurée
- Mettre en place une segmentation par VLAN
- Centraliser les utilisateurs avec Active Directory
- Mettre en place DNS et DHCP
- Sécuriser les communications avec un pare-feu
- Mettre en place une DMZ
- Déployer des services applicatifs
- Mettre en place une solution de support informatique
- Superviser l'infrastructure
- Mettre en place une stratégie de sauvegarde
- Tester la restauration des données
- Documenter l'ensemble de l'infrastructure

## Technologies

- Cisco Packet Tracer
- Active Directory
- Windows Server
- Linux
- pfSense
- GLPI
- Zabbix
- MariaDB / PostgreSQL
- Apache / Nginx
- Git / GitHub

## Architecture

Le réseau est organisé autour d'un routeur Edge, d'un switch cœur et de plusieurs switches d'accès.

Les différents services sont séparés par VLAN afin d'améliorer la sécurité et l'administration du réseau.
